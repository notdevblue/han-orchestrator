이 양식은 완료 문항의 현재 선택과 유효 조건을 보여 준다. JSON 정본의 id·답·상태·승인 범위를 유지한다. 상태 머리글·전체 이력 링크는 CLI가 생성하며 완료 답을 재출력하지 않는다. 현재 선택은 작성자가 문서 `body`에 쓰고 다른 절에서 명확하면 별도 요약은 만들지 않는다.
